# NVIDIA OCR Data

Private photos, annotations, generated crops, TAO exports, and manifests belong here. The data subdirectories are ignored by Git.

- `source-pages/`: original private page photos.
- `annotations/`: canonical WoodApp JSON annotations.
- `recognition-crops/`: generated OCRNet measurement crops.
- `tao-ocdnet/`: generated OCDNet dataset export.
- `tao-ocrnet/`: generated OCRNet dataset export.
- `manifests/`: writer-aware train/validation/test JSONL manifests.
