# NVIDIA OCR Models

Model files are private build artifacts and are ignored by Git.

- `pretrained/`: official compatible NVIDIA TAO pretrained checkpoints.
- `checkpoints/`: fine-tuned WoodApp detector/recognizer checkpoints.
- `exported/`: ONNX/TensorRT exports used by runtime inference.

Do not commit `.onnx`, `.engine`, `.etlt`, `.pth`, `.pt`, or `.ckpt` files.
